# 目标

先实现一个**状态输入版 Diffusion Policy**，暂时不实现图像输入和真实机器人控制。

项目应当完成以下流程：

```text
读取状态-动作数据
        ↓
构造 observation history 和 future action sequence
        ↓
对 action sequence 加噪
        ↓
模型预测噪声
        ↓
计算 DDPM loss 并训练
        ↓
保存 checkpoint
        ↓
加载 checkpoint
        ↓
通过 DDPM sampler 生成动作序列
        ↓
在 toy sim 环境中 rollout
```

当前阶段的目标是**跑通训练和评估闭环**，不是实现完整论文级 Diffusion Policy。

## 3. `diffusion/noise_scheduler.py`

实现 DDPM 噪声调度器。

要求提供：

```python
class NoiseScheduler:
    def add_noise(...):
        ...

    def step(...):
        ...
```

其中 `add_noise` 用于训练阶段：

```text
x_t = sqrt(alpha_bar_t) * x_0 + sqrt(1 - alpha_bar_t) * noise
```

`step` 用于推理阶段，从 `x_t` 更新到 `x_{t-1}`。

需要支持：

```text
num_train_timesteps
beta_start
beta_end
betas
alphas
alpha_bars
```

## 7. `diffusion/ddpm.py`

```python
        ...
```

